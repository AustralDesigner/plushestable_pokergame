# plushestable_pokergame
Your plushies. Your table. Your next poker rival.

Plushie Poker Table is a browser-based, single-player Texas Hold’em game where you compete against a cast of plushie opponents with different playing styles and personalities.

Build your own table, choose your rivals, manage your chips, and find out which plushie rules the table!

✨ Features

Customizable tables: Choose between 1 and 9 plushie opponents, with the option to seat multiple copies of the same character.

Unique opponents: Each plushie has its own playing tendencies, from cautious decision-making to aggressive betting and bluffing.

Preset lineups: Jump straight into a random table, an all-Cinnamoto lineup, a Blastoise and BCI Rojo table, or a mixed roster.

Adjustable starting stacks: Start each game with 1,000, 2,000, or 5,000 chips.

Texas Hold’em gameplay: Play through the pre-flop, flop, turn, and river betting rounds.

Adjustable game speed: Speed up the action whenever you want.

Session statistics: Review your results, chip counts, biggest pots, and notable hands when the game ends.

Responsive interface: Play in a browser on desktop or mobile devices.

🎮 How to Play

Open the game and select Play.

Choose the plushies you want at your table.

Select your starting chip stack and begin the game.

Make your decisions during each betting round: fold, call, raise, or go all-in when available.

Try to outplay every opponent and be the last player with chips remaining.

You can also check the in-game poker guide for a quick reminder of hand rankings and basic betting concepts.

🚀 Getting Started

No installation, dependencies, or build tools are required.

Download or clone this repository.

Open index.html in a modern web browser.

Start playing!

The game is built with HTML, CSS, and vanilla JavaScript. The character images are embedded in the HTML file, so no separate asset folder is required. Google Fonts are loaded externally and may fall back to system fonts if unavailable.
